
# hostel_vacancy_hub
Designed and developed an intuitive hostel accommodation platform, enabling students to seamlessly search and view available rooms with detailed information. The system streamlines the room allocation process while providing admins with secure access to manage and update hostel details efficiently.
# 🚀 Features:

- Student Features:
  - ✅ View available hostel accommodations on campus.
  - ✅ Select specific hostels to explore.
  - ✅ Access detailed information, including room numbers and the number of beds.

- Admin Features:
  - ✅ Add new hostel details.
  - ✅ Update existing hostel information.
  - ✅ Delete outdated or incorrect hostel records. 

# 🛠 Technologies Used:
- Python Libraries(Tkinter, PIL-Frontend)
- MySql Workbench(Backend)
